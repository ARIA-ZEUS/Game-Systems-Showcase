## Overview

This repository presents selected areas of my work in multiplayer game development, including custom Lua resources, gameplay systems, interface engineering, and server integrations.

My development work spans both client-side and server-side functionality, with an emphasis on performance, maintainability, security, and integration with existing game environments.

## Development Areas

### Custom Game Interfaces

Design and implementation of game interfaces using Lua and native rendering technologies.

Areas of work include:

- Custom HUDs and interactive panels
- DX-based user interfaces for MTA:SA
- Interactive controls, tables, and navigation
- Custom loading screens and transitions
- Resolution-aware interface layouts
- UI assets and design implementation

### Gameplay Systems

Development and customization of multiplayer gameplay functionality.

Areas of work include:

- Event-driven gameplay features
- Player and group management systems
- Role-based administrative functionality
- Client-server event handling
- Gameplay state management
- Integration with existing server resources

### MTA:SA Development

Technical work involving:

- Lua client-side scripting
- Lua server-side scripting
- DX rendering and interface interaction
- Resource configuration and lifecycle
- Event validation
- Server-side authorization
- Performance-oriented rendering

### FiveM Development

Development and integration work involving:

- Lua-based server resources
- Gameplay feature customization
- Integration with existing frameworks
- Server-side event handling
- Resource debugging and maintenance
- Deployment and runtime troubleshooting
